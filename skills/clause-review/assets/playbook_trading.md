# プレイブック：商社（trading）売買・供給契約

デモ用たたき台。自社＝仲介・売買を行う商社（買主または売主）の立場を想定。
判定基準：🟢 自社標準どおり／🟡 許容ライン内（条件付き受諾・交渉余地あり）／🔴 NGライン（要修正）。

## 1. 貿易条件（INCOTERMS）

| 項目 | 内容 |
|---|---|
| 自社標準 | INCOTERMS 2020 を明記し、CIF または CFR（自社が売主の場合）／FOB（自社が買主の場合） |
| 🟡 許容 | INCOTERMS 2010 の指定（2020への更新を提案）。DAP は保険・輸送コストを価格転嫁できる場合のみ |
| 🔴 NG | INCOTERMSの版が未記載／条件と矛盾する個別規定（例：FOBなのに買主が船積み前リスクを負担） |
| 交渉トーク | 「版の明記は双方の解釈齟齬の防止のためで、条件自体は変えません」 |

## 2. 所有権移転・危険負担

| 項目 | 内容 |
|---|---|
| 自社標準 | 危険負担はINCOTERMSに一致。所有権移転は代金完済時（所有権留保） |
| 🟡 許容 | 所有権移転を船積時とする場合、L/C等の決済保全があれば可 |
| 🔴 NG | 危険負担がINCOTERMSと乖離／検収前に危険負担のみ買主移転／所有権移転時期の規定なし |
| 交渉トーク | 「危険負担はINCOTERMSと一致させるのが国際慣行。個別条項での上書きは保険求償で双方不利」 |

## 3. 支払条件・決済

| 項目 | 内容 |
|---|---|
| 自社標準 | 取消不能L/C一覧払い（新規相手）／T/T送金は既存与信枠内のみ。支払サイトは船積後60日以内 |
| 🟡 許容 | サイト90日（与信枠・保険でカバーできる場合）。D/P決済は少額かつ継続取引先のみ |
| 🔴 NG | サイト120日超／O/A（オープンアカウント）を新規相手に適用／L/C条件の一方的変更権 |
| 交渉トーク | 「サイト延長は金利負担の価格反映とセットで検討可能」 |

## 4. 与信・保全

| 項目 | 内容 |
|---|---|
| 自社標準 | 期限の利益喪失条項／信用不安時の出荷停止権／担保・親会社保証（与信超過時） |
| 🟡 許容 | 保証の代替として貿易保険・ファクタリング |
| 🔴 NG | 期限の利益喪失条項の削除／信用不安時の対応規定なし |
| 交渉トーク | 「双方向の条項なので貴社にも同等の保護があります」 |

## 5. 不可抗力・制裁・輸出管理

| 項目 | 内容 |
|---|---|
| 自社標準 | 不可抗力に制裁・輸出規制を含める。制裁対象者との取引でないことの表明保証。該非判定への協力義務 |
| 🟡 許容 | 表明保証を「知る限り」に限定（デューデリ実施が前提） |
| 🔴 NG | 制裁・輸出管理条項なし（三国間・国際取引の場合）／制裁発動時の解除権なし |
| 交渉トーク | 「外為法・OFAC対応は両社のコンプライアンス上の必須要件です」 |

## 6. 価格改定・数量

| 項目 | 内容 |
|---|---|
| 自社標準 | 長期契約は市況連動フォーミュラまたは定期価格見直し条項。数量過不足の許容幅（±5%） |
| 🟡 許容 | 固定価格は1年以内の契約のみ |
| 🔴 NG | 1年超の固定価格で改定条項なし／一方のみに有利な価格調整権 |

## 7. 下請法（国内仕入で自社が親事業者に該当する場合）

| 項目 | 内容 |
|---|---|
| 自社標準 | 支払期日＝受領後60日以内・書面交付・買いたたき/減額禁止に抵触しない条件 |
| 🔴 NG | 受領後60日超の支払／検収を支払起算点にする規定（受領起算が原則） |
| 交渉トーク | 「下請法の強行規定のため当社側で譲歩できない項目です」 |

## 8. 準拠法・紛争解決

| 項目 | 内容 |
|---|---|
| 自社標準 | 日本法・日本商事仲裁協会（JCAA）仲裁 |
| 🟡 許容 | 第三国法（英国法・シンガポール法）＋SIAC/ICC仲裁 |
| 🔴 NG | 相手国法＋相手国裁判所の専属管轄 |

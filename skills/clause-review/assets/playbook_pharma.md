# プレイブック：製薬（pharma）ライセンス・CDA契約

デモ用たたき台。自社＝開発品を導入するライセンシー（製薬企業）の立場を想定。

## 1. 知財帰属・改良発明

| 項目 | 内容 |
|---|---|
| 自社標準 | 既存知財は各自帰属。ライセンシー単独の改良発明はライセンシー帰属。共同発明は共有＋実施許諾の相互無償 |
| 🟡 許容 | 改良発明のライセンサーへのグラントバック（非独占・無償・対象化合物に限定なら可） |
| 🔴 NG | ライセンシー改良発明のライセンサー単独帰属／独占的グラントバック（独禁法上の拘束条件リスク） |
| 交渉トーク | 「独占的グラントバックは公取委の知財ガイドライン上も問題となり得ます」 |

## 2. マイルストーン・ロイヤリティ

| 項目 | 内容 |
|---|---|
| 自社標準 | マイルストーンは客観的達成基準（当局申請受理・承認取得等）で定義。ロイヤリティは純売上ベース・料率と控除項目を明記 |
| 🟡 許容 | 開発マイルストーンの一部前倒し支払（総額が変わらない場合） |
| 🔴 NG | 達成基準が主観的（「開発の順調な進捗」等）／特許満了後もロイヤリティ継続（延長分の根拠なし）／純売上の定義・控除項目なし |
| 交渉トーク | 「達成基準の客観化は支払紛争の予防で、双方のガバナンス説明にも必要です」 |

## 3. 独占権・競業避止

| 項目 | 内容 |
|---|---|
| 自社標準 | 対象地域・対象適応症での独占的ライセンス。独占維持の最低努力義務（diligence）は具体的マイルストーンで定義 |
| 🟡 許容 | 最低販売数量コミット（市場前提が合理的な場合） |
| 🔴 NG | 独占なのに対象範囲（地域・適応症）が曖昧／ライセンサーの一方的独占解除権（診断的基準なし） |

## 4. 秘密保持・データ権利

| 項目 | 内容 |
|---|---|
| 自社標準 | 秘密保持期間は契約終了後5年（技術情報は10年）。開発・薬事データはライセンシーが薬事目的で自由利用可 |
| 🟡 許容 | 期間7年への延長 |
| 🔴 NG | 無期限の秘密保持（範囲無限定）／薬事申請へのデータ利用にライセンサーの都度承諾が必要 |
| 交渉トーク | 「薬事目的のデータ利用制限は承認取得＝双方の収益化を遅らせます」 |

## 5. GxP・品質

| 項目 | 内容 |
|---|---|
| 自社標準 | GMP適合・品質契約の別途締結・監査権（事前通知付き年1回＋for cause） |
| 🔴 NG | 監査権なし／品質契約締結義務なし（商用供給を伴う場合） |

## 6. 表明保証・補償

| 項目 | 内容 |
|---|---|
| 自社標準 | ライセンサーによる第三者知財非侵害の表明保証（知る限り）。補償は相互・過失割合ベース。賠償上限＝受領済み対価総額 |
| 🟡 許容 | 賠償上限の除外（故意・重過失・知財侵害・秘密保持違反） |
| 🔴 NG | 知財非侵害の表明保証なし／ライセンシーのみ片面的な無限責任 |

## 7. 解除・終了後措置

| 項目 | 内容 |
|---|---|
| 自社標準 | 重大違反時の解除権（是正期間60日）。開発中止時のライセンシー任意解除権（事前通知90日）。終了後のデータ・在庫の取扱いを明記 |
| 🔴 NG | ライセンシー側の任意解除権なし（開発リスクを負うのに撤退手段がない）／終了後措置の規定なし |
| 交渉トーク | 「撤退条件の明確化は当社稟議の必須要件です（＝これが無いと決裁が下りず締結が遅れます）」 |

## 8. 透明性GL・コンプライアンス

| 項目 | 内容 |
|---|---|
| 自社標準 | 医療機関等への支払がある場合の透明性ガイドライン対応・腐敗防止（贈収賄禁止）条項 |
| 🔴 NG | 腐敗防止条項なし（海外ライセンサーとの取引の場合） |

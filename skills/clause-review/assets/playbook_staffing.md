# プレイブック：人材（staffing）派遣・紹介予定派遣 基本契約

デモ用たたき台。自社＝派遣元・職業紹介事業者（人材会社）の立場を想定。

## 1. 契約スキーム（派遣／請負の区分）

| 項目 | 内容 |
|---|---|
| 自社標準 | 指揮命令関係の所在を明記（派遣＝派遣先が指揮命令）。請負と派遣を混在させない |
| 🔴 NG | 「請負」と題しながら発注者が労働者に直接指揮命令する規定（偽装請負）／指揮命令の所在が不明確 |
| 交渉トーク | 「区分の明確化は貴社の偽装請負リスク（労働契約申込みみなし制度）の回避にもなります」 |

## 2. 派遣可能期間・抵触日

| 項目 | 内容 |
|---|---|
| 自社標準 | 事業所単位・個人単位の期間制限（3年）と抵触日通知義務（派遣先→派遣元）を明記 |
| 🔴 NG | 抵触日通知の規定なし／期間制限を超える継続を前提とした規定 |
| 交渉トーク | 「派遣法の強行規定であり、通知がないと当社は派遣契約を締結できません（法26条）」 |

## 3. 事前面接・特定行為の禁止

| 項目 | 内容 |
|---|---|
| 自社標準 | 派遣労働者を特定する行為（事前面接・履歴書送付要求）の禁止を明記。紹介予定派遣の場合のみ面接可 |
| 🔴 NG | 派遣開始前の面接・選考を派遣先に認める規定（紹介予定派遣を除く） |

## 4. 紹介手数料・返戻金（紹介予定派遣・職業紹介）

| 項目 | 内容 |
|---|---|
| 自社標準 | 手数料＝理論年収の35%。返戻金＝入社後1ヶ月以内退職80%・3ヶ月以内50%・6ヶ月以内20%（自己都合退職のみ） |
| 🟡 許容 | 手数料30%まで／返戻期間の微調整（総返戻率が標準を超えない範囲） |
| 🔴 NG | 手数料25%未満／返戻期隓1年超／会社都合退職・解雇まで返戻対象に含める規定 |
| 交渉トーク | 「返戻は定着リスクの分担であり、貴社側の受入環境要因（会社都合）まで当社が負担する建て付けは応じられません」 |

## 5. 直接雇用の取扱い

| 項目 | 内容 |
|---|---|
| 自社標準 | 派遣終了後の直接雇用は妨げない（派遣法上、禁止条項は無効）。ただし紹介手数料相当の紹介料規定を置く |
| 🔴 NG | 直接雇用時の紹介料規定なし（引き抜きが無償になる）／直接雇用自体を禁止する条項（法33条で無効・コンプラ指摘対象） |

## 6. 料金・支払条件

| 項目 | 内容 |
|---|---|
| 自社標準 | 月末締め翌月末払い。時間単価と割増（時間外・深夜・休日）の負担を明記 |
| 🟡 許容 | 翌々月10日払いまで |
| 🔴 NG | 支払サイト60日超／派遣先都合の休業時の料金免除（休業手当負担の転嫁） |

## 7. 個人情報・秘密保持

| 項目 | 内容 |
|---|---|
| 自社標準 | 派遣労働者・候補者の個人情報は目的内利用限定・保持期間を明記（選考終了後は返却/削除） |
| 🔴 NG | 候補者情報の無期限保持・目的外利用（自社採用DB化等）を認める規定 |

## 8. 損害賠償・責任

| 項目 | 内容 |
|---|---|
| 自社標準 | 賠償は直接かつ現実の損害に限定・上限＝直近6ヶ月の取引額。派遣労働者の故意重過失は求償ルートを明記 |
| 🟡 許容 | 上限12ヶ月分 |
| 🔴 NG | 無限責任／派遣労働者の行為への無過失責任を派遣元に負わせる規定 |

## 運用メモ

- CLMデモ環境に登録する場合は、各mdをWord化（docxスキル）してアップロードし、レビュータスクを起票しておく。
- 業種デモの持ち時間が短い場合の推し逸脱：商社＝第5条（危険負担乖離）、製薬＝第12条（撤退不能）、人材＝第3条（事前面接）＋第6条（返戻）。
- 登場する企業名・案件・数値はすべて架空のものである。

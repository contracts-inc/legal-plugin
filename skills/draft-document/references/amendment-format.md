# 変更覚書の推奨フォーマットと文例

> **このファイルについて:** 代表ユースケースである変更覚書の推奨フォーマットと汎用文例（ダミー）を定義します。文例はすべて汎用ダミーであり、特定顧客・組織の情報は含みません。実際の生成では原契約から引用した正確な情報に置き換えてください。

---

## 1. 推奨フォーマット

```
                    〇〇契約 変更覚書

 ［甲の名称］（以下「甲」という。）と［乙の名称］（以下「乙」という。）とは、
 甲乙間で ［原契約の締結日：YYYY年M月D日］ に締結した「［原契約の正式名称］」
 （以下「原契約」という。）について、以下のとおり変更することに合意し、本変更覚書
 （以下「本覚書」という。）を締結する。

 第1条（原契約の変更）
   原契約第X条（［条項見出し］）を次のとおり変更する。

   【変更前】
   ［原契約の該当条文を原文どおり引用］

   【変更後】
   ［変更後の条文］

 第2条（効力発生日）
   本覚書は、［効力発生日：YYYY年M月D日 ※要確認］から効力を生じる。

 第3条（原契約の効力）
   本覚書に定めのない事項については、原契約の定めをそのまま適用する。

 本覚書の成立を証するため、本書2通を作成し、甲乙記名押印のうえ、各1通を保有する。

   ［締結日：YYYY年M月D日 ※要確認］

   甲：［住所・名称・記名押印欄］
   乙：［住所・名称・記名押印欄］
```

---

## 2. 変更種別ごとの文例（ダミー）

### 変更（文言・数値の変更）
```
第1条（契約期間の変更）
  原契約第5条（契約期間）を次のとおり変更する。

  【変更前】
  本契約の有効期間は、YYYY年M月D日からYYYY年M月D日までとする。

  【変更後】
  本契約の有効期間は、YYYY年M月D日からYYYY年M月D日まで（1年間延長）とする。
```

### 追加（新条項の追加）
```
第1条（条項の追加）
  原契約に次の条項を追加する。

  【追加条項】
  第X条（〇〇）
  ［追加する条文 ※要確認］
```

### 削除（既存条項の削除）
```
第1条（条項の削除）
  原契約第X条（［条項見出し］）を削除する。
  これに伴い、原契約第X条以降の条番号を繰り上げる（※要確認：繰り上げの要否）。
```

### 別紙差し替え
```
第1条（別紙の差し替え）
  原契約の別紙〇を、本覚書に添付する別紙〇（改訂版）に差し替える。
```

---

## 3. 記載上の注意

- 「変更前」は必ず原契約の該当条文を **原文どおり** 引用する（推測で書き換えない）。
- 締結日・効力発生日など、原契約やユーザー入力から確定できない値は `※要確認` を付す。
- 甲乙の定義・順序は原契約に合わせる。
- 文書冒頭または脚注に「ドラフト（草案）・要法務確認」の注記を付す。

---

## カスタマイズガイド

> 1. 自社の変更覚書雛形の体裁（表題・前文・後文の定型文）に合わせてフォーマットを更新する。
> 2. 変更種別ごとの定型文言を自社の実務に合わせて調整する。
> 3. 署名欄（記名押印 / 電子署名）の様式を自社運用に合わせる。

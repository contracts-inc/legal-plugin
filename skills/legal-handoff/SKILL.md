# legal-handoff：法務レビュー依頼パッケージ（UC2）

## 前提
- `../_shared/clm_rules.md` と `../_shared/industry_presets.md` を必ず読み込むこと。
- 取引背景（相手方・取引スキーム・金額感・スケジュール）が不明な場合、1〜2問だけヒアリングする（質問攻めにしない）。
- CLM未接続時はサンプル契約書で続行（「サンプルデータで実演中」と明示）。

## 手順

### Step 1. 対象契約書と背景の把握
1. CLM文書指定があれば `download_document` で取得。なければ clause-review と同じ手順でタスクから特定。
2. 取引背景を整理：当事者・スキーム（売主/買主/仲介、ライセンサー/ライセンシー、派遣/請負 等）・金額・期限。

### Step 2. 法務論点の抽出
業種プリセットの観点で論点を抽出する：
- trading：外為法・安全保障貿易管理（該非判定・制裁リスト）／独禁法（カルテル・再販価格）／下請法
- pharma：薬機法／GxP省令／透明性ガイドライン／要配慮個人情報
- staffing：職安法・労働者派遣法（許可要件・抵触日・事前面接禁止）／偽装請負（指揮命令関係の判定）／下請法

各論点は「事実（契約のどこに書いてあるか）→ 論点（何が問題になりうるか）→ 自社の仮見解 → 法務への質問」の4点セットで書く。仮見解のない丸投げ論点を作らない。

### Step 3. 関連法令の引用（e-Gov MCP）
1. `search_law_by_keyword` で該当法令を特定し、`get_law_text` で該当条文を取得する。
2. 論点ごとに条文番号付きで抜粋を添付（例：労働者派遣法40条の2〔派遣可能期間〕）。
3. 条文は関係部分のみ引用し、全文貼り付けはしない。

### Step 4. 依頼パッケージの生成
以下の構成のMarkdownを生成する：

```
# 法務レビュー依頼：{契約名}
## 1. 背景（3行以内）
## 2. 取引スキーム（テキスト図）
## 3. 論点リスト（優先度順・各論点に仮見解と質問）
## 4. 関連法令抜粋（条番号付き）
## 5. 希望回答期限と理由
```

### Step 5. CLMへの投稿（要承認）
プレビューを提示し、承認後に `post_task_comment` でCLMタスクへ投稿する。
必要に応じて `change_document_property_values` でステータス系プロパティ（例：レビュー依頼中）の更新を提案する。

## 出力フォーマット
1. 依頼パッケージ全文（上記構成）
2. CLMタスクリンク（固定URL形式）
3. 補足：「法務は開いた瞬間に判断に入れる状態」になっているかのセルフチェック（背景説明の往復が要らないか）

# 契約類型別

## 1. 業務委託・準委任

- 委託の性質は。選択肢: 役務提供（成果物なし）/ 成果物の完成を伴う / 混在。
- 検収の要否と基準は。選択肢: 検収あり（基準を明文化）/ 検収あり（基準は個別合意）/ 検収なし。
- 検収期間は何日か。期間内に異議がない場合の扱い（みなし合格）を認めるか。
- 契約不適合責任（旧瑕疵担保）の期間は。選択肢: 3ヶ月 / 6ヶ月 / 1年 / 民法の原則による。
- 再委託の可否形式は。選択肢: 事前の書面承諾 / 事前通知 / 包括同意 / 禁止。
- 要員の指定・交代について要求はあるか（キーパーソン条項、交代時の承諾）。
- 指揮命令関係の切り分けを明記するか（**偽装請負の回避**。受託者側の労務管理責任を明記するか）。
- 作業場所・作業時間・持ち帰り可否の定めを置くか。
- 委託料の支払条件は。選択肢: 月額固定 / 実績時間精算（上限あり）/ 成果物単位 / マイルストーン。
- 追加作業・仕様変更時の費用取扱いを定めるか。選択肢: 別途見積・書面合意 / 一定範囲は無償 / 定めない。
- 委託者の協力義務（資料提供、意思決定期限）を明記するか。

## 2. システム開発請負

- 開発方式は。選択肢: ウォーターフォール / アジャイル / 混在。
- アジャイルの場合、成果物の確定方法と対価の考え方をどう定めるか。
- 仕様変更管理の手続を定めるか（変更管理書面、影響評価、費用・工期の再見積）。
- 工期遅延時の扱いは。選択肢: 遅延損害金（率を確認）/ 協議による / 定めない。
- 契約不適合責任の期間と範囲は。無償修補の範囲をどこまで求めるか。
- 第三者ソフトウェア・OSS の使用について事前承諾・リスト提出を要求するか。
- 成果物のソースコード・設計書の引渡しを要求するか。
- 開発環境・テストデータに本番の個人情報を使わせるか（**使わせない場合は明記**）。
- 検収後の運用移行・引継ぎ義務を定めるか。
- 中途終了時の出来高精算と成果物の帰属をどうするか。
- 多段階契約（基本契約＋個別契約）の構成にするか。優先関係をどう定めるか。

## 3. 秘密保持契約（NDA）

- 自社の立場は。選択肢: 開示者中心 / 受領者中心 / 相互。
- 秘密情報の定義方法は。選択肢: 秘密指定したものに限る / 開示された情報すべて / 口頭は事後書面化を要する。
- 除外事由として認めるものは。選択肢: 公知情報 / 独自開発 / 第三者からの正当取得 / 開示前に保有 / 法令に基づく開示。
- 秘密保持期間は。選択肢: 1年 / 3年 / 5年 / 契約終了後も無期限。許容範囲も確認する。
- 目的外利用の禁止をどこまで厳格にするか（競合製品開発への利用禁止まで求めるか）。
- 開示可能な範囲は。選択肢: 役員・従業員のみ / 親子会社・関連会社を含む / 委託先・アドバイザーを含む。
- 契約終了時の返還・破棄義務と、バックアップ・残留コピーの例外を認めるか。
- 残留記憶（Residual Knowledge）条項を受諾するか。
- 損害賠償に加えて差止請求を明記するか。違約金を設けるか。
- 成果物・共同検討で生じた知財の帰属を NDA 段階で定めるか。
- 反社条項・輸出管理条項を NDA にも入れるか。

## 4. SaaS・クラウドサービス

- 自社の立場は。選択肢: ベンダー / 顧客 / 両方。
- SLA の要否と稼働率の基準は。選択肢: 99.9% / 99.5% / 99% / SLA なし。許容範囲も確認する。
- 稼働率の算定方法（計画停止の除外、障害の定義）を明記するか。
- SLA 未達時の措置は。選択肢: サービスクレジット（率を確認）/ 解約権 / 損害賠償 / 措置なし。
- サポート窓口・応答時間・復旧目標（RTO / RPO）に要求はあるか。
- 顧客データの所有権・利用範囲をどう定めるか（統計利用・AI学習への利用を認めるか）。
- サブプロセッサ（再委託先クラウド）の開示と変更通知を要求するか。
- データセンターの所在国に要件はあるか。
- データポータビリティ（終了時のデータ返却形式・期限）を要求するか。
- 終了後のデータ保持期間と削除義務をどう定めるか。
- サービス内容の一方的変更・機能廃止をどこまで認めるか。
- サービス終了（EOL）時の予告期間は。選択肢: 3ヶ月 / 6ヶ月 / 1年。
- 利用料の改定条件は。選択肢: 事前通知のみで可 / 上限率を設定 / 合意を要する。
- 最低利用期間・最低利用料の設定を認めるか。
- 監査・セキュリティ質問票への対応義務をどこまで求めるか（第三者認証の提出で足りるか）。
- 利用規約・約款の変更を一方的に認めるか（**約款準備者側 / 相手側で方針を分ける**）。
- API 利用制限・レート制限の扱いを定めるか。

## 5. ライセンス

- 自社の立場は。選択肢: ライセンサー / ライセンシー。
- 許諾の範囲は。選択肢: 使用のみ / 複製・改変を含む / 再頒布を含む / サブライセンス可。
- 独占性は。選択肢: 非独占 / 独占 / 一定分野・地域で独占。
- 許諾地域・期間・用途の制限をどう定めるか。
- 対価の方式は。選択肢: 一括 / 年額 / ランニングロイヤリティ（率と算定基礎）/ ミニマムギャランティ。
- ロイヤリティ報告・監査権をどこまで求めるか（頻度、監査費用の負担、差額発生時の扱い）。
- 改良・派生物の権利帰属をどう定めるか。
- ライセンサーの保証範囲は。選択肢: 第三者権利の非侵害を保証 / 現状有姿（無保証）/ 限定保証。
- 第三者から侵害を主張された場合の対応義務（防御・代替提供・返金）をどう定めるか。
- 商標の使用許諾を含む場合、品質管理・表示方法の定めを置くか。
- 契約終了後の使用停止・廃棄と、既存顧客への継続提供（sell-off期間）を認めるか。
- ソースコードエスクローを要求するか。

## 6. 売買・製造

- 自社の立場は。選択肢: 売主 / 買主。
- 検査の方法と期間は。選択肢: 全数検査 / 抜取検査 / 無検査（受入のみ）。期間も確認する。
- 契約不適合責任の期間は。選択肢: 6ヶ月 / 1年 / 2年 / 商法の原則による。
- 所有権と危険負担の移転時期は。選択肢: 引渡時 / 検査合格時 / 代金完済時。
- 納期遅延時の遅延損害金の率と上限を定めるか。
- 最低購入義務・購入予測の提示義務を負うか。
- 価格改定条項（原材料費・為替変動の反映）を設けるか。選択肢: 協議条項のみ / 指標連動 / 一定期間固定。
- 製造物責任（PL）の分担とリコール費用の負担をどう定めるか。
- 保険加入義務（PL保険）を要求するか。付保額の水準は。
- 金型・治具の所有権と保管責任をどう定めるか。
- 部材の供給継続義務・生産終了時の予告期間を要求するか。
- 品質保証（規格適合、含有化学物質、RoHS 等）の要求水準は。
- 支給材・貸与品の管理責任をどう定めるか。
- 継続的取引の場合、個別契約の成立方法（注文書・注文請書、みなし承諾）を定めるか。

## 7. 販売代理・OEM

- 契約の型は。選択肢: 販売代理（取次）/ 再販売（買取）/ 紹介・レベニューシェア / OEM 製造。
- 独占権を与えるか。選択肢: 非独占 / テリトリー内独占 / 完全独占。
- テリトリー（地域・顧客セグメント）の定め方は。テリトリー外への販売を禁止するか（**独占禁止法上の制約に注意**）。
- 最低販売数量・最低購入義務を設けるか。未達時の措置は。選択肢: 独占解除 / 契約解除 / 補償金 / 措置なし。
- 競合品の取扱い制限を課すか（**不当な拘束条件に当たらないかを確認**）。
- 再販売価格に関与するか（**再販売価格の拘束は原則として独禁法違反**である旨を前提に確認）。
- 最恵待遇（MFN）条項を要求されるか。受諾方針は。
- 顧客情報・顧客帰属の扱いをどう定めるか（終了後の顧客の引継ぎ）。
- 販売支援・トレーニング・販促費の負担をどう分担するか。
- 終了時の在庫の買戻し義務を負うか。
- 終了時の補償（代理店保護）を求められるか。適用法によって強行規定がある国はあるか。
- 商標・ブランド使用のガイドラインを定めるか。

## 8. 共同研究開発

- 費用分担と持分の考え方は。選択肢: 均等 / 出資比率 / 実費負担 / 一方が全額負担。
- 成果（発明・著作物）の帰属は。選択肢: 共有 / 主たる発明者に帰属 / 費用負担者に帰属。
- 共有特許の出願・維持費用の分担と、出願国の決定方法をどう定めるか。
- 共有持分の第三者への譲渡・ライセンスに相手方の同意を要するか（**特許法上の共有の制約を前提に確認**）。
- 自己実施の可否と、相手方への対価支払の要否をどう定めるか。
- バックグラウンドIPの持込範囲と、相手方への使用許諾条件をどう定めるか。
- 研究成果の公表（論文・学会発表）の事前承諾と、承諾までの期間をどう定めるか。
- 研究従事者の秘密保持と、大学・研究機関が関与する場合の扱いをどうするか。
- 中止・離脱の条件と、その場合の成果の帰属・費用精算をどう定めるか。
- 事業化のフェーズ移行（別途の実施契約への移行）を定めるか。
- 独占禁止法上の共同研究開発ガイドラインへの適合を確認するか。

## 9. 保守・運用

- 対応時間帯は。選択肢: 平日日中 / 平日24時間 / 365日24時間。
- 障害の重要度区分と、区分ごとの応答時間・復旧目標を定めるか。
- 対応義務の範囲は。選択肢: 是正措置まで / 原因調査まで / 回避策の提示まで。
- 対象範囲外の作業（追加開発、他社製品起因）の扱いと費用をどう定めるか。
- 保守料の改定条件は。選択肢: 事前通知のみ / 上限率あり / 合意を要する。
- サポート終了（EOL / EOSL）の予告期間は。選択肢: 6ヶ月 / 1年 / 2年。
- バージョンアップの提供義務と、旧バージョンのサポート期間をどう定めるか。
- 遠隔アクセス・本番環境へのアクセス権限をどう管理するか。
- 作業記録・報告の頻度と形式を定めるか。
- 保守不能・保守拒否となる条件（無断改変等）を明記するか。

## 10. 人材派遣・紹介

- 契約の型は。選択肢: 労働者派遣 / 職業紹介 / 業務請負 / 準委任。
- **労働者派遣法の要件**（派遣可能期間、抵触日通知、事業所単位・個人単位の制限）を契約に反映するか。
- 指揮命令者・派遣先責任者の特定を契約に明記するか。
- 派遣と請負の区分（**偽装請負の回避**）をどう担保するか。
- 派遣料金・紹介手数料の水準と、支払条件をどう定めるか。
- 紹介の場合、早期離職時の返還規定（返還率・期間）をどう定めるか。
- 直接雇用への切替（引抜き）を禁止するか。禁止期間と違約金の扱いは。
- 派遣労働者の交代要求の可否と手続を定めるか。
- 同一労働同一賃金への対応（待遇情報の提供）をどう扱うか。
- 秘密保持・成果物の権利帰属を派遣労働者にも及ぼす手当をするか。

## 11. 賃貸借

- 対象は。選択肢: 不動産（オフィス・倉庫）/ 設備・機器 / ソフトウェア以外の物品。
- 期間と更新方法は。選択肢: 普通借家 / 定期借家 / 自動更新。
- 中途解約権と予告期間、違約金の扱いをどう定めるか。
- 賃料改定の条件（増減額請求、指標連動）をどう定めるか。
- 敷金・保証金の額と返還条件、償却の有無をどう定めるか。
- 修繕義務の分担（大規模修繕 / 小修繕）をどう定めるか。
- 原状回復の範囲と負担（通常損耗の扱い）をどう定めるか。
- 転貸・用途変更の可否をどう定めるか。
- 保険加入義務と付保範囲を要求するか。
- 契約不適合・使用不能時の賃料減額を明記するか。

## 12. 広告・制作

- 成果物の権利帰属は。選択肢: 発注者に全部譲渡 / 制作者に留保しライセンス / 用途限定の譲渡。
- 二次利用・媒体拡大の可否と追加対価の考え方をどう定めるか。
- 使用期間・使用媒体・使用地域の制限をどう定めるか。
- 出演者・モデル・声優の肖像権・実演家の権利処理を誰が行うか。
- タレント起用時の不祥事対応（差替え費用、損害の負担）をどう定めるか。
- 第三者素材（ストックフォト、フォント、音源）のライセンス確認義務を誰が負うか。
- 権利侵害・表示規制違反（景表法・薬機法等）の責任分担をどう定めるか。
- 修正回数の上限と追加費用の扱いを定めるか。
- 制作物の実績公開（ポートフォリオ掲載）を認めるか。
- 検収基準と、公開後の瑕疵対応をどう定めるか。

## 13. 建設工事

- **建設業法**上の要件（書面の記載事項、一括下請の禁止、見積期間）を契約に反映するか。
- 工期変更・設計変更時の手続と費用精算をどう定めるか。
- 契約不適合責任の期間は。選択肢: 1年 / 2年 / 構造耐力上主要な部分は10年。
- 完成検査・引渡しの手続と、部分引渡しの可否をどう定めるか。
- 遅延損害金の率と上限を定めるか。
- 前払金・中間払・出来高払の条件をどう定めるか。
- 現場の安全管理責任と労災の分担をどう定めるか。
- 第三者への損害（近隣補償）の負担をどう定めるか。
- 保険（請負業者賠償責任保険、工事保険）の付保義務と付保額を要求するか。
- 下請への支払（**下請法・建設業法の支払期日**）の遵守をどう担保するか。

# 規制・領域別

## 14. 下請法適用取引

- 自社は親事業者・下請事業者のどちらに該当するか。資本金区分と取引類型を確認する。
- 該当する取引類型は。選択肢: 製造委託 / 修理委託 / 情報成果物作成委託 / 役務提供委託。
- 支払期日を「受領後60日以内」に設定しているか（**法定の上限**）。
- 発注書面（3条書面）の記載事項を契約・注文書で満たしているか。
- 禁止行為への該当を防ぐ定めがあるか。選択肢: 受領拒否 / 支払遅延 / 減額 / 返品 / 買いたたき / 購入強制 / 不当な経済上の利益提供要請 / 不当な給付内容の変更・やり直し。
- 有償支給材の対価を下請代金から控除する場合の取扱いを定めているか。
- 遅延利息（年14.6%）の定めを認識しているか。
- 下請取引の記録（5条書類）の保存期間を定めているか。

## 15. 個人情報・データ利活用

- 取り扱うデータの種類は。選択肢: 個人情報 / 個人データ / 要配慮個人情報 / 仮名加工情報 / 匿名加工情報 / 個人関連情報 / 個人情報を含まない。
- 自社の立場は。選択肢: 委託元 / 委託先 / 共同利用 / 第三者提供の提供元 / 提供先。
- 委託・共同利用・第三者提供のどの整理で扱うかを契約で明確にするか。
- 越境移転の有無と、移転先国・移転の根拠（同意 / 基準適合体制）をどう定めるか。
- Cookie・広告識別子等の個人関連情報の提供について確認義務を定めるか。
- 事故時の本人通知・個人情報保護委員会への報告の役割分担をどう定めるか（**報告義務は原則として委託元**）。
- データの二次利用（統計化、サービス改善、AI学習）を認めるか。認める場合の条件は。
- 保存期間・削除の要求と、削除完了の証明をどう求めるか。
- 従業者の教育・アクセス権限管理の要求水準は。
- 監査の方法は。選択肢: 現地監査 / 質問票 / 第三者認証の提出。
- GDPR 等の外国法の適用がある取引はあるか（SCC・DPA の締結要否）。

## 16. 独占禁止法・優越的地位

- 自社が取引上優位に立つ取引はあるか。相手方の依存度が高い取引はあるか。
- 優越的地位の濫用に当たり得る要求をしていないか。選択肢: 協賛金・センターフィーの要請 / 従業員派遣の要請 / 返品 / 支払遅延 / 一方的な取引条件の変更 / 購入強制。
- 相手方から濫用的な要求を受けた場合の対応方針とエスカレーション先を定めるか。
- 再販売価格の拘束、テリトリー制限、競合品取扱制限、抱き合わせ販売の可否について方針を持つか。
- 共同行為（共同研究、共同購買、標準化）を行う場合の事前確認プロセスを定めるか。
- 下請取引・フリーランス取引について、独禁法・下請法・フリーランス法のいずれの観点で確認するか。

## 17. 海外取引

- 相手方の所在国は。頻度の高い国はどこか。
- 準拠法として受諾できる国の範囲は。
- 紛争解決は。選択肢: 日本の裁判所 / 相手国の裁判所 / 第三国での仲裁。仲裁機関・仲裁地・言語の希望は。
- ウィーン売買条約（CISG）の適用を排除するか。
- 契約書の言語と正文をどう定めるか。翻訳の齟齬時の優先関係は。
- 輸出管理（外為法、EAR、キャッチオール規制）の確認プロセスを契約に反映するか。
- 経済制裁・禁輸国・denied party スクリーニングの表明保証を求めるか。
- 関税・輸送条件（インコタームズ）をどう定めるか。
- 為替変動リスクの負担と、支払通貨をどう定めるか。
- 源泉徴収税・租税条約の適用と、グロスアップ条項の扱いをどう定めるか。
- 現地の強行規定（代理店保護法、労働法、データローカライゼーション）を確認する体制があるか。
- 政府調達・外国公務員が関与する取引はあるか。

## 18. AI・生成物

- 自社の立場は。選択肢: AIサービスの提供者 / 利用者 / AI開発の委託者 / 受託者。
- AI への入力データの取扱いをどう定めるか（秘密情報・個人情報の投入可否）。
- 入力データを提供者側の**学習に利用させるか**。選択肢: 一切禁止 / オプトアウト前提で許容 / 統計化した範囲で許容。
- 生成物の権利帰属と利用範囲をどう定めるか。
- 生成物が第三者の権利を侵害した場合の責任分担をどう定めるか（提供者の補償の有無）。
- 出力の正確性について保証を求めるか（**ハルシネーションを前提に無保証とするか**）。
- 学習データの適法性について表明保証を求めるか。
- モデル・重み・ファインチューニング結果の権利帰属をどう定めるか。
- AI 利用の開示義務（成果物に AI を使用した旨の表明）を求めるか。
- 人間による確認プロセス（Human in the loop）を契約上の義務とするか。
- 各国の AI 規制（EU AI Act 等）の適用があり得るか。

## 19. OSS・知財コンプライアンス

- 成果物・納品物への OSS 使用を認めるか。選択肢: 事前承諾を要する / リスト提出を要する / 制限しない。
- 使用を禁止するライセンス種別はあるか（コピーレフト系: GPL / AGPL / LGPL 等）。
- OSS のライセンス表示・ソース開示義務の履行責任を誰が負うか。
- SBOM（部品表）の提出を要求するか。
- 第三者の特許・商標の非侵害について表明保証を求めるか。調査義務の範囲は。
- 自社の知財を相手方に提供する場合の使用範囲・表示方法を定めるか。
- 職務発明規程との整合（受託者側従業員の発明の扱い）を確認するか。

## 20. 業種別の規制対応（金融 / 医療 / 電気通信 / 人材）

**金融**
- 外部委託先管理（監督指針・システムリスク管理）の要求事項を契約に反映するか。
- 当局検査・監査への協力義務、再委託先への監督義務を要求するか。
- 顧客情報の取扱い（金融分野のガイドライン）に追加要件はあるか。
- 業務継続計画（BCP）・復旧目標の要求水準は。

**医療・ヘルスケア**
- 要配慮個人情報の取扱いに追加要件はあるか。
- 薬機法・医療広告規制の遵守責任をどう分担するか。
- 治験・臨床研究が関わる場合の被験者データ・成果の扱いをどう定めるか。
- 医療情報システムの安全管理ガイドライン（3省2ガイドライン）への適合を要求するか。

**電気通信**
- 通信の秘密の保護に関する義務を契約に反映するか。
- 電気通信事業法上の届出・登録の要否と、外部委託時の責任分担をどう定めるか。

**人材**
- 労働者派遣法・職業安定法の遵守をどう担保するか（類型別「人材派遣・紹介」も参照）。
- フリーランス法（特定受託事業者に係る取引の適正化）の適用取引はあるか。取引条件の明示義務をどう履行するか。

## 21. ESG・人権デューデリジェンス

- サプライチェーンに対する人権・環境の要求を契約に入れるか。
- 遵守を求める規範は。選択肢: 自社の調達方針 / 国連指導原則 / 業界基準 / 顧客からの要求事項。
- 禁止事項として明記するものは。選択肢: 強制労働 / 児童労働 / 差別・ハラスメント / 違法な長時間労働 / 環境法令違反。
- 調査・監査・是正要求の権利をどこまで求めるか。
- 違反時の措置は。選択肢: 是正要求 / 取引停止 / 契約解除。
- 紛争鉱物・化学物質規制への対応を要求するか。
- 再委託先・二次サプライヤーへの遵守伝達義務を課すか。

## 22. 贈収賄防止・コンプライアンス

- 贈収賄防止条項を入れるか。適用を意識する法令は。選択肢: 不正競争防止法（外国公務員贈賄）/ FCPA / UK Bribery Act。
- 政府・公的機関との取引や、公務員が関与する取引はあるか。
- 相手方に表明保証（過去の違反なし、制裁対象でないこと）を求めるか。
- 反社会的勢力の排除条項に加えて、コンプライアンス違反時の即時解除を定めるか。
- 利益相反・リベート・過度な接待贈答の禁止を契約に明記するか。
- 通報窓口・調査協力義務を定めるか。
- 違反時の措置は。選択肢: 是正要求 / 契約解除 / 損害賠償 / 支払停止。

# ヒアリング記入フォーム（テンプレート）

> **このファイルについて:** 確認事項が8件以上になる場合に、ユーザーへ渡す記入用フォームの雛形です。**該当する項目だけを抜き出して配布**します（該当しない契約類型・規制の項目は削除する）。項目の追加が必要な場合は `interview-guide.md` / `interview-guide-by-type.md` から同じ形式で転記します。

---

## 記入方法

- 各項目の `回答: [ ]` の `[ ]` に、**選択肢の番号**を記入してください。
- 番号のあとに金額・期間などの数値が必要な項目は、番号のあとに続けて記入してください（例: `[ 4 / 3,000万円 ]`）。
- 複数選択できる項目は、番号をカンマ区切りで記入してください（例: `[ 1, 3, 5 ]`）。
- わからない項目・決まっていない項目は **`保留`** と記入してください。後で個別に確認します。空欄のままでも構いません。
- 担当が分かれる項目は、分かる方だけ記入して他の方に回していただいて構いません。

# Wordコメント挿入ガイドライン

> **このファイルについて:** 本ファイルは、契約書レビュー時にWordコメント（吹き出し）として挿入する指摘内容のフォーマットと記載ルールを定義します。組織のレビュー運用に合わせてカスタマイズしてください。

---

## 1. コメントの挿入位置

各指摘内容を、対象となる条項の**該当箇所にWordコメント（吹き出し）として挿入**する。

- コメントは指摘対象のテキスト範囲を選択した状態で挿入する
- 条項全体ではなく、問題のある具体的な文言・フレーズに対して挿入する
- 1つの条項に複数の指摘がある場合は、それぞれの該当箇所に個別のコメントを挿入する

---

## 2. コメントに含める情報

各コメントには以下の情報を含める。

| フィールド | 説明 |
|-----------|------|
| **重大度** | 🟢 GREEN / 🟡 YELLOW / 🔴 RED |
| **指摘理由** | なぜこの条項が基準から逸脱しているか |
| **修正の根拠** | プレイブックの該当基準、関連法令、または一般的な商慣行への参照 |

---

## 3. コメントのフォーマット

以下のフォーマットに従って記載する。

```
【重大度】🔴 RED
【指摘理由】損害賠償の上限が設定されておらず、青天井となっている。
【修正の根拠】プレイブック §2.1 に基づき、賠償上限は直近12ヶ月間の委託料相当額を基準とする。上限なしはエスカレーション対象。
```

```
【重大度】🟡 YELLOW
【指摘理由】再委託が事前通知制となっており、自社基準の事前承諾制と異なる。
【修正の根拠】プレイブック §2.4 に基づき、再委託は事前の書面承諾を要する。フォールバックとして「事前通知＋異議なければ承諾とみなす」方式は許容。
```

```
【重大度】🟢 GREEN
【指摘理由】秘密保持期間が5年と設定されており、自社基準（3年）より長いが許容範囲内。
【修正の根拠】プレイブック §2.5 に基づき、存続条項の秘密保持期間は2年〜5年の範囲で調整可能。交渉不要。
```

---

## 4. 禁止事項

- **【禁止】** コメント内に修正案の文言そのものを記載してはならない。修正案は変更履歴（Track Changes）として本文に反映する。コメントはあくまで指摘の理由と根拠を記録する場である。
- **【禁止】** 重大度・指摘理由・修正の根拠のいずれかを省略してはならない。3項目すべてを記載すること。
- **【禁止】** 複数の指摘を1つのコメントにまとめてはならない。指摘ごとに個別のコメントを挿入すること。

---

## カスタマイズガイド

> 本ファイルを自社向けにカスタマイズする際のポイント:
>
> 1. **コメントフォーマット:** 自社のレビュー管理に必要な追加フィールド（例: 担当者、期限、参照条文番号、エスカレーション先）を追加
> 2. **重大度ラベル:** 自社のリスク分類体系に合わせてラベルや色を変更
> 3. **挿入位置のルール:** 自社のレビュー粒度に応じて調整（条項単位 vs. 文言単位）
> 4. **禁止事項:** 自社のレビュー品質基準に応じてルールを追加・変更
